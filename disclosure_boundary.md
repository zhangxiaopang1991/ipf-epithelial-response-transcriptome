# Disclosure boundary

Included: analysis scripts, module definitions, run order, package requirements, and reproducibility documentation.

Excluded: raw GEO matrices, platform annotation archives, derived sample-level CSV results, unpublished manuscript text, author identities, institutional correspondence, and credentials.

The public release must preserve the manuscript's interpretation boundary: no reflux, laryngopharyngeal reflux, microaspiration, laryngoscopy, causal, prognostic, or predictive inference is supported by these datasets.
