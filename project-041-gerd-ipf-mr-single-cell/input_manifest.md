# Public input manifest

| Input | Public source | Role |
|---|---|---|
| GERD summary statistics | GWAS Catalog GCST90000514 | Primary exposure |
| IPF summary statistics | GWAS Catalog GCST009758 | Primary outcome and reverse-direction candidate |
| IPF lung single-cell metadata and sparse matrix | GEO GSE136831 | Donor-aware exploratory localization |

Large files are not versioned in this repository. The scripts assume that downloaded files are placed in the project working directory or in the project-relative paths specified by the corresponding script. Do not substitute LPR, reflux severity or microaspiration phenotypes for the GERD GWAS exposure.
