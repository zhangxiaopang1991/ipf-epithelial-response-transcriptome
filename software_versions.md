# Software requirements

- R 4.6.1 or a documented compatible version
- Bioconductor 3.23 or a documented compatible version
- GEOquery, limma, GSVA, robustbase, clusterProfiler, org.Hs.eg.db, AnnotationDbi
- Optional, not required for the reported manuscript claims: msigdbr and fgsea

The audited local environment is recorded in `docs/software_environment_2026-08-27.md`. A public release must include the exact `sessionInfo()` output from its own clean run.
